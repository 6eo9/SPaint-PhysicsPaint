# Installation
## Requirements
Linux (tested on Arch Linux with Hyprland)
Rust and Cargo
Git (optional)
A working graphics driver with desktop graphics support

## Build from source
Clone the repository:
git clone https://github.com/6eo9/SPaint-PhysicsPaint.git
Or Download it -> in the top click the green code button and click "Download ZIP"
Unzip it if needed.
cd SPaint-PhysicsPaint
### Build and run the application:
cargo run --release

## Build without running
To compile an optimized release build:
cargo build --release
The compiled executable will be located in:
target/release/SPaint
Run it with:
./target/release/SPaint
